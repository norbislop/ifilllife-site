# Images

Put approved photos and illustrations here. Astro copies this directory as-is.
Use descriptive filenames such as `founder-portrait.webp`, explicit width and
height attributes, and useful alt text. Use `withBase('images/filename.webp')`
for URLs so images also work on a subdirectory deployment.

The starter uses original inline SVG and system fonts, so it makes no requests
to external image or font providers.
